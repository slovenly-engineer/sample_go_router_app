# レビューチェックリスト

## 実装完了時のチェックリスト

### コード品質

- [ ] `flutter analyze` でエラーがない
- [ ] `dart format` でフォーマットされている
- [ ] テストが通過する
- [ ] コード生成が実行されている（必要に応じて）

### アーキテクチャ

- [ ] Feature-Firstアーキテクチャに従っている
- [ ] ディレクトリ構造が標準に従っている
- [ ] ルーティングが適切に実装されている
- [ ] 状態管理が適切に実装されている

### パターン適用

- [ ] AppNavigatorパターンが適用されている
- [ ] ViewModelパターンが適用されている
- [ ] エラーハンドリングパターンが適用されている

## レビュー時の確認項目

### 機能追加時

- [ ] 機能が `lib/features/` 配下に配置されている
- [ ] 機能モジュールの構造が標準に従っている
- [ ] ルート定義が正しく作成されている
- [ ] ViewModelが適切に実装されている
- [ ] テストが追加されている

### 画面遷移追加時

- [ ] `AppNavigator` を使用している
- [ ] `BuildContext` に依存していない
- [ ] ルートタイプが適切に選択されている

### 状態管理追加時

- [ ] Riverpodを使用している
- [ ] 状態が不変に保たれている
- [ ] ViewModelパターンに従っている

## リリース前の確認項目

- [ ] すべてのテストが通過する
- [ ] 静的解析エラーがない
- [ ] コード生成が最新の状態
- [ ] ドキュメントが更新されている（必要に応じて）
